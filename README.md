# TDD

Practice test-driven development (write tests first).

**Install**

```sh
pipx install cursorcult
cursorcult link TDD
```

Rule file format reference: https://cursor.com/docs/context/rules#rulemd-file-format

**When to use**

- You want tests to drive design and prevent regressions.
- You’re adding features or fixing bugs and want behavior locked down first.

**What it enforces**

- Write or update a failing test before changing production code.
- Implement the minimal change to pass the test, then refactor safely.
- Work in small, test‑validated increments.

**Credits**

- Concept popularized by Kent Beck through Extreme Programming and TDD.
